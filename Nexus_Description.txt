[size=5][b]AbsoluteZero — Mouse Alignment Assist for Starfield[/b][/size]

A lightweight SFSE plugin that gently centers your ship's mouse aim when idle during flight, alongside an optional [b]Locked Reticule[/b] mode that drives ship steering directly while keeping your crosshair perfectly dead center. No joystick input, no throttle injection, no binding wizard — just smooth exponential decay and robust reticule locking.

Mechanically inspired by [url=https://www.nexusmods.com/starfield/users/4477498]Xilandro[/url]'s [b]Flight Controls Autoalign[/b] (out of support since 2024). Logic was independently developed.

[quote][b]Note[/b]: This is a standalone sister project to [url=https://www.nexusmods.com/starfield/mods/210]AbsoluteHOTAS[/url]. If you already use AbsoluteHOTAS, you don't need this — enable [font=Courier New]bAlignmentAssist = true[/font] in [font=Courier New]AbsoluteHOTAS.ini[/font] instead.[/quote]

[size=4][b]Installation[/b][/size]
[list=1]
[*] Extract [font=Courier New]AbsoluteZero.dll[/font] and [font=Courier New]AbsoluteZero.ini[/font] to [font=Courier New]Data\SFSE\Plugins\[/font]
[/list]

[size=4][b]Configuration[/b][/size]
Edit [font=Courier New]Data\SFSE\Plugins\AbsoluteZero.ini[/font]:

[b][MouseAlign][/b]
[list]
[*] [font=Courier New]bEnabled[/font] (Default: [font=Courier New]true[/font]) — Enable/disable alignment assist.
[*] [font=Courier New]fRadius[/font] (Default: [font=Courier New]140.0[/font]) — Accumulator distance from center within which assist activates (0–200). Default is 70% of the circular range.
[*] [font=Courier New]iIdleMs[/font] (Default: [font=Courier New]80[/font]) — Milliseconds the mouse must be idle before decay starts.
[*] [font=Courier New]fDecayRate[/font] (Default: [font=Courier New]12.0[/font]) — Exponential decay speed. Higher values snap to center faster.
[*] [font=Courier New]iPollRateHz[/font] (Default: [font=Courier New]120[/font]) — Polling frequency in Hz.
[*] [font=Courier New]iSuppressKey[/font] (Default: [font=Courier New]0x42[/font] / B) — Hold this key to suppress auto-centering. Set to [font=Courier New]0[/font] to disable. Uses [url=https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes]Virtual Key Codes[/url].
[*] [font=Courier New]bLogEnabled[/font] (Default: [font=Courier New]false[/font]) — Write debug info to [font=Courier New]AbsoluteZero.log[/font].
[/list]

[b][VirtualJoy][/b]
[list]
[*] [font=Courier New]bVirtualJoy[/font] (Default: [font=Courier New]false[/font]) — Enable Locked Reticule mode. Locks your crosshair to the center and drives steering directly via a virtual accumulator.
[*] [font=Courier New]iVJoyToggleKey[/font] (Default: [font=Courier New]0x60[/font] / Numpad 0) — Virtual key code for toggling Locked Reticule mode on the fly.
[*] [font=Courier New]bVJoyToggleAlt[/font] (Default: [font=Courier New]true[/font]) — Require the Alt key to be held when pressing the toggle key.
[/list]

[size=4][b]Live Tuning (In-Game Hotkeys)[/b][/size]
Adjust settings on the fly without leaving the cockpit:

[list]
[*] [font=Courier New]Alt + Numpad+ / Numpad-[/font] — Radius ↑/↓ (±2.0)
[*] [font=Courier New]Ctrl + Numpad+ / Numpad-[/font] — Idle delay ↑/↓ (±10 ms)
[*] [font=Courier New]Shift + Numpad+ / Numpad-[/font] — Decay rate ↑/↓ (±0.5)
[*] [font=Courier New]Ctrl + Alt + Numpad0[/font] — Toggle enable/disable
[*] [font=Courier New]Alt + Numpad0[/font] — Toggle Locked Reticule (Virtual Joy) mode (key configurable in INI)
[*] [font=Courier New]Ctrl + Alt + S[/font] — Save current settings to INI
[/list]

All changes are logged to [font=Courier New]AbsoluteZero.log[/font] (always, regardless of [font=Courier New]bLogEnabled[/font]). Use [font=Courier New]Ctrl+Alt+S[/font] to persist your tuned values so they survive a game restart.

[size=4][b]How It Works[/b][/size]
[list=1]
[*] [b]Hook[/b]: At startup, the plugin AOB-scans for Starfield's rotational writer block and installs a trampoline hook to capture the source object pointer.
[*] [b]Alignment Assist[/b]: A polling thread observes the captured mouse accumulator. When the mouse is idle and within the configured radius, it applies exponential decay to gently center the aim.
[*] [b]Locked Reticule (VJoy)[/b]: When enabled, a C++ callback synchronously executes directly from the game's execution hook. It safely intercepts mouse movements per frame, zeros the vanilla accumulator to perfectly lock your crosshair in the center with zero jitter, and injects the delta into a normalized virtual accumulator that directly drives ship steering offsets. It fully mirrors the vanilla alignment assist and sustained turn mechanics!
[/list]

[size=4][b]Compatibility[/b][/size]
[list]
[*] [color=#ff0000][b]Do NOT load alongside AbsoluteHOTAS[/b][/color] — both hook the same writer block. The plugin detects [font=Courier New]AbsoluteHOTAS.dll[/font] at load time and gracefully disables itself.
[*] Compatible with other SFSE plugins that don't modify the rotational writer block.
[/list]
