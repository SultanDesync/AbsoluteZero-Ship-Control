[center][size=6][color=#00ccff][b]AbsoluteZero 1.3.0[/b][/color][/size]
[size=4][b][color=#ffaa00]Mouse alignment and optional locked-reticule steering for Starfield.[/color][/b][/size][/center]

AbsoluteZero gently returns ship mouse aim toward center after input stops. Its optional Locked Reticule mode keeps the crosshair centered while translating mouse motion into steering. It runs standalone and now integrates with the shared Absolute Control menu.

[line]

[center][size=5][color=#ffcc00][b]Features[/b][/color][/size][/center]

[list]
[*][b]Idle mouse centering[/b] with configurable radius, delay, and exponential decay.[/*]
[*][b]Hold-to-suppress binding[/b] for temporary unrestricted mouse aim.[/*]
[*][b]Locked Reticule mode[/b] for centered-crosshair steering when used standalone.[/*]
[*][b]Native MOD OPTIONS page[/b] through Absolute Control, including binding capture and live settings.[/*]
[*][b]Interactive centering lab[/b] that responds continuously to mouse movement and demonstrates the configured activation radius, idle delay, and return rate.[/*]
[*][b]Center on press mode[/b] with its own binding as an alternative to automatic idle centering.[/*]
[*][b]Headless fallback[/b] through the INI and live-tuning hotkeys.[/*]
[*][b]Safe HOTAS pairing[/b] through explicit axis ownership and one shared writer hook.[/*]
[/list]

[line]

[center][size=5][color=#ffaa00][b]AbsoluteHOTAS compatibility[/b][/color][/size][/center]

AbsoluteZero and AbsoluteHOTAS cannot safely write pitch/yaw simultaneously. When both current builds are installed, AbsoluteZero owns mouse pitch/yaw steering and HOTAS yields its pitch/yaw stick bindings. HOTAS continues to control roll, strafe, throttle, buttons, and profiles while retaining the single shared writer hook.

[b]Install both only when you want mouse steering to own pitch and yaw.[/b] A joystick cannot control those two axes while AbsoluteZero is present. Locked Reticule/VirtualJoy mode is unavailable in the paired configuration; native idle centering remains supported.

Older or incompatible HOTAS versions fail closed instead of installing competing writer hooks.

[line]

[center][size=5][color=#00ccff][b]Requirements and installation[/b][/color][/size][/center]

[list]
[*]Starfield 1.16.242 or 1.16.244[/*]
[*][url=https://sfse.silverlock.org/]SFSE[/url] 0.2.20 or later[/*]
[*]No Address Library required[/*]
[*]Absolute Control is optional but recommended for the native in-game editor[/*]
[/list]

Install normally with MO2 or Vortex, or place [font=Courier New]AbsoluteZero.dll[/font] and [font=Courier New]AbsoluteZero.ini[/font] in [font=Courier New]Data\SFSE\Plugins\[/font].

With Absolute Control installed, open the Pause Menu, select [color=#ffaa00][b]MOD OPTIONS[/b][/color], and choose [b]AbsoluteZero[/b].

[line]

[center][size=5][color=#00ccff][b]Live tuning[/b][/color][/size][/center]

[list]
[*][font=Courier New]Alt+Numpad+ / Alt+Numpad-[/font] — radius ±2.0[/*]
[*][font=Courier New]Ctrl+Numpad+ / Ctrl+Numpad-[/font] — idle delay ±10 ms[/*]
[*][font=Courier New]Shift+Numpad+ / Shift+Numpad-[/font] — decay rate ±0.5[/*]
[*][font=Courier New]Ctrl+Alt+0[/font] — toggle idle centering[/*]
[*][font=Courier New]Alt+Numpad0[/font] — toggle standalone Locked Reticule mode[/*]
[*][font=Courier New]Ctrl+Alt+S[/font] — save current settings[/*]
[/list]

Logging is off by default and occurs only when [font=Courier New]bLogEnabled=true[/font].
